# ヘルスカレンダー v2 設計ドキュメント

作成日: 2026-06-04

## 概要

スマホメインで毎日使う健康管理アプリ。カロリー収支（基礎代謝込み）と生理サイクルの把握が主目的。

## 対象ユーザー

- スマホ（iOS/Android）メインで使用
- 毎朝・毎晩、その日の健康データを記録・確認する

---

## 1. 画面構成

タブを2つから3つに変更する。

```
現在:  📅 カレンダー  |  📊 グラフ
変更後: 🌸 今日  |  📅 カレンダー  |  📊 グラフ
```

「今日」タブを先頭に置き、アプリ起動時に最初に表示する。

---

## 2. プロフィール設定 & 基礎代謝

### 2-1. 入力項目

| 項目 | 単位 |
|------|------|
| 身長 | cm |
| 体重 | kg |
| 年齢 | 歳 |

### 2-2. 表示タイミング

- アプリ初回起動時（プロフィール未設定の場合）に自動表示
- グラフタブに「⚙️」アイコンを設置し、いつでも変更可能

### 2-3. BMR計算式

女性向け Mifflin-St Jeor 式を使用：

```
BMR = 10 × 体重(kg) + 6.25 × 身長(cm) − 5 × 年齢 − 161
```

計算結果を localStorage に保存する（`health_profile_v1`）。

### 2-4. データ保存キー

```js
// 既存（変更なし）
localStorage: 'health_cal_v1'  // 日別データ

// 新規追加
localStorage: 'health_profile_v1'  // { height, weight, age, bmr }
```

## 3. カロリー収支の変更

### 3-1. 収支の計算式

```
収支 = 摂取カロリー − 運動消費カロリー − 基礎代謝(BMR)
```

- 「消費カロリー」入力欄は運動分のみを手入力
- 基礎代謝はプロフィール設定から自動適用
- BMR未設定の場合は「摂取 − 運動」のみで収支を表示（従来通り）

### 3-2. 収支の色分け

| 収支 | 表示 | 色 |
|------|------|-----|
| マイナス | 痩せ方向 ✅ | 緑 |
| ±0付近（±100以内） | 維持 | グレー |
| プラス | 太り方向 ⚠️ | オレンジ |

### 3-3. モーダル（日別入力）の変更

```
変更前:
  摂取カロリー / 消費カロリー / 体重 / 生理チェック

変更後:
  摂取カロリー / 消費カロリー（運動分）/ 体重 / 生理チェック
  収支プレビュー = 摂取 − 運動 − BMR（リアルタイム表示）
```

## 4. 生理サイクル改善

### 4-1. 生理〇日目の表示

生理開始日入力後、7日間のカレンダーセルのフェーズラベルを変更：

```
変更前: 「生理中」（固定）
変更後: 「生理1日目」「生理2日目」…「生理7日目」
```

### 4-2. 予測ロジックの優先順位

- 実際の生理開始日が入力された瞬間、その周期の予測表示を消す
- 実際の入力が常に予測より優先される
- 前倒し・遅延どちらも対応：入力した日を新しい基準として28日周期を再計算

### 4-3. フェーズラベル一覧

| サイクル日 | フェーズ | ラベル（変更後） |
|-----------|---------|----------------|
| 1〜7日目 | 生理中 | 生理〇日目 |
| 8〜13日目 | 卵胞期 | 痩せやすい時期（変更なし） |
| 14日目 | 排卵日 | 排卵日（変更なし） |
| 15〜21日目 | 黄体期前半 | むくみやすい時期（変更なし） |
| 22〜28日目 | 黄体期後半 | 生理前・むくみ注意 |

## 5. 「今日」タブの画面設計

### 5-1. 表示レイアウト

```
┌─────────────────────────────┐
│ 🌸 今日  2026年6月4日（木）  │
├─────────────────────────────┤
│  📊 カロリー収支             │
│  摂取      1,800 kcal       │
│  消費（運動）  300 kcal     │
│  基礎代謝   1,400 kcal（自動）│
│  ──────────────────────     │
│  収支  +100 kcal ⚠️太り方向  │
├─────────────────────────────┤
│  🩸 生理3日目                │
│  今は：生理中（安静にしよう）  │
├─────────────────────────────┤
│  ⚖️ 体重  55.2 kg           │
└─────────────────────────────┘
```

### 5-2. データ未入力時の表示

「今日のデータがまだありません → タップして記録」と表示し、タップでモーダルを開く。

### 5-3. フェーズ別アドバイス文言

| フェーズ | アドバイス |
|---------|----------|
| 生理中 | 安静にしよう。無理な運動はNG |
| 痩せやすい時期 | ダイエットのチャンス！動こう |
| 排卵日 | 体が活発な時期 |
| むくみやすい時期 | 塩分・水分に注意 |
| 生理前・むくみ注意 | 食欲が増えやすい時期。意識して |

## 7. スコープ外（今回は実装しない）

- サプリ記録・登録機能
- うんこ回数記録
- 美容イベント記録（髪・ネイル・ホワイトニング・皮膚科・脱毛）

これらは v3 以降で対応する。

---

## 8. 技術方針

- 純粋な HTML/CSS/JS（単一ファイル）で完結
- 外部ライブラリ・API不使用
- データは localStorage のみ（サーバー不要）
- 既存データ（`health_cal_v1`）との後方互換性を維持
